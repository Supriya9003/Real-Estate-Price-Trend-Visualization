# Real-Estate-Price-Trend-Visualization
Real Estate Price Trend Visualization

Project Overview

This project is an interactive Power BI dashboard designed to analyze real estate property price trends across different regions and months.

Dashboard Features

- Average Property Price analysis
- Average Price by Month and Region
- Price Appreciation by Region
- Conditional-formatting Heat Map
- Interactive Month slicer
- Interactive Region slicer
- Regional price comparison
- Monthly price trend analysis

Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Data Visualization

Key Insights

The dashboard helps identify differences in property prices across regions and analyze how prices change over time.

The Price Appreciation visual provides a regional comparison, while the monthly trend chart shows changes in average property prices throughout the year.
